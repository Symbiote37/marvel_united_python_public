# Marvel United: Terminal Engine

A lightweight, terminal-based digital engine and companion for **Marvel United**. 

### ⚠️ Current Status: Alpha Testing
This project is currently in **Alpha**. The core gameplay loops are functional, but you may encounter occasional bugs or edge cases as the architecture is actively being refined and stabilized.

### 📦 Included Content
This engine currently supports the complete base game and initial wave of expansions:
* **✔️ Season 1 Heroes & Villains:** Fully playable roster of all characters from the Season 1 content drops.
* **✔️ Ultimate Campaign Mode:** Features a fully integrated campaign mode based on the incredible **Marvel United Ultimate Campaign** map created by **@dom2d**. Huge credit and thanks to them for designing the campaign structure!
* **🚧 Infinity Gauntlet Mode:** Currently under construction. Thanos is inevitable, but his code is still compiling.

### 🚀 How to Play
To launch the engine, ensure you have Python 3 installed on your system. 

1. Clone or download this repository.
2. Open your terminal or command prompt.
3. Navigate to the project folder.
4. Run the launcher script:
   ```bash
   python main.py
